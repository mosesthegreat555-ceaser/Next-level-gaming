# Website — Next Level Gaming & Esports Arena

Built using **HTML5 + CSS3 + plain JavaScript**. The main files are `index.html`, `about.html`, `packages.html`, `package-detail.html`, `calculator.html`, `contact.html`, `css/style.css`, `js/data.js`, and `js/main.js`.

## Open the website

- Easiest: double-click `index.html` (all pages and scripts are local).
- Recommended in VS Code: install the **Live Server** extension, right-click `index.html`, select **Open with Live Server**.
- Alternatively, from this folder run `python -m http.server 5500` and visit `http://localhost:5500`.

## Test

From this folder, if Node.js is installed: `node tests/calculator.test.js`.

## Notes

- The quotation feature works entirely in your browser.
- Form validation works, but the contact form **does not send emails**.
- The package pricing is for the coursework prototype. No bookings or payments are processed.
- You can deploy this static website to GitHub Pages once you are ready.
